# 🐙 How to Upload Your Project to GitHub
### Step-by-Step Guide (No coding knowledge needed)

---

## WHAT IS GITHUB?
GitHub is a free website where you can **store and share your code safely online**.  
It's like Google Drive — but specially made for code files.

---

## STEP 1 — Create a Free GitHub Account

1. Go to 👉 **https://github.com**
2. Click **"Sign up"**
3. Enter:
   - Username: e.g. `aravindhan0066`
   - Email: `aravindhan0066@gmail.com`
   - Password: (choose a strong password)
4. Complete the verification
5. Click **"Create account"**
6. Verify your email (GitHub sends a confirmation email)

---

## STEP 2 — Create a New Repository (Project Folder)

1. After logging in, click the **"+"** button at the top right
2. Click **"New repository"**
3. Fill in:
   - **Repository name:** `online-exam-system`
   - **Description:** `Online Exam System built with Google Apps Script`
   - **Visibility:** Choose **Public** (free) or **Private** (only you can see)
   - ✅ Tick **"Add a README file"**
4. Click the green **"Create repository"** button

---

## STEP 3 — Upload Your Files to GitHub

You have **5 files** to upload:
- `Code.gs`
- `Index.html`
- `appsscript.json`
- `.gitignore`
- `README.md`

### How to upload:

1. You are now inside your new repository page
2. Click **"uploading an existing file"** (you'll see this link in the middle of the page)
   - OR click **"Add file"** → **"Upload files"**
3. Drag and drop ALL 5 files into the upload area
   - OR click **"choose your files"** and select all 5 files
4. Scroll down to **"Commit changes"** section
5. In the first box, type: `Initial upload - Online Exam System`
6. Click the green **"Commit changes"** button

---

## STEP 4 — Verify Your Files Are Uploaded

You should now see all your files listed:
```
online-exam-system/
├── Code.gs
├── Index.html
├── appsscript.json
├── .gitignore
└── README.md
```

The README will automatically display nicely at the bottom of the page.

---

## STEP 5 — Copy Your Repository Link

Your repository URL will look like:
```
https://github.com/aravindhan0066/online-exam-system
```

**Save this link** — you can share it with anyone!

---

## HOW TO UPDATE FILES LATER

When you make changes to your code and want to update GitHub:

1. Go to your repository on GitHub
2. Click on the file you want to update (e.g. `Code.gs`)
3. Click the **pencil icon** (Edit) at the top right of the file
4. Make your changes
5. Scroll down → click **"Commit changes"**

OR to replace a file:
1. Click **"Add file"** → **"Upload files"**
2. Upload the new version of the file
3. It will replace the old one
4. Click **"Commit changes"**
